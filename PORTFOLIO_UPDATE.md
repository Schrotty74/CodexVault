# Portfolio update rule

This repository is a public project by Schrotty74.

Before a public release, check whether the project card and detail pages in
the portfolio need an update:

https://schrotty74.github.io/Portfolio/

Update the portfolio only when public-facing information changes, such as the
main description, status, screenshots, supported platforms, repository URL,
download URL or privacy documentation. The project needs matching English and
German detail pages, and the GitHub profile should link to the English page.

The repository-wide privacy and publication rules in `AGENTS.md` apply to all
portfolio material. Public screenshots and example data must use only synthetic,
anonymized or clearly fictional data.
